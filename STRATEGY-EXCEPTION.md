## Definitions

- **Public API**: the names that the packages `@qtsurfer/core`, `@qtsurfer/indicators` and `@qtsurfer/strategy`
  export from their package entry points.
- **Strategy**: a trading strategy or a description of one (a QTScript file, or code that extends or calls
  classes of the Public API, and the code that a tool generates from any of them) that uses the Library only
  through the Public API and that contains no part of the Library, whole or modified.
